SNSレシピ抽出 プライバシーポリシー

制定日：2026年10月17日（同日改定：Gemini対応、チャット送信方式の追加、料理写真の保存、動画サムネイルの取得）

本ポリシーは、Chrome拡張機能「SNSレシピ抽出」（以下「本拡張機能」）における利用者情報の取り扱いについて定めるものです。

1. 取り扱う情報

APIキー利用者が設定画面で入力したAPIキー（Anthropic APIキー、Google Gemini APIキー）。利用者のブラウザ内（chrome.storage.local）にのみ保存されます。
ページの内容利用者が「レシピを抽出」ボタンを押したときに限り、表示中のタブから取得する投稿本文（キャプション）、画像の代替テキスト、ページURL。
スクリーンショット「画面も解析する」がオンの場合（API方式のみ）に限り、抽出ボタンを押した時点の表示中タブの画像。
AIの回答「チャットに送る」方式で、利用者が取り込み欄に貼り付けたAIの回答。
手動入力テキスト利用者が貼り付け欄に入力したテキスト。
料理の写真「料理の写真も保存する」がオンの場合に限り、抽出ボタンを押した時点で画面に表示されている投稿画像の部分を切り出した画像。動画の投稿では、投稿のサムネイル画像（表示中のページ、投稿ページ、またはInstagramの画像サーバーから読み込み）を使用します。保存したレシピとともに利用者のブラウザ内にのみ保存され、外部へは送信されません。
保存したレシピ抽出結果のうち、利用者が保存したもの（料理の写真を含む）。利用者のブラウザ内（chrome.storage.local）にのみ保存されます。

本拡張機能は、閲覧履歴の収集、バックグラウンドでのページ読み取り、利用状況の解析（アナリティクス）を行いません。

2. 利用目的

取得した情報は、レシピ情報を抽出・表示・保存するためにのみ使用します。

3. 第三者への提供

本拡張機能には、利用者が設定で選ぶ2つの方式があります。

「チャットに送る」方式：本拡張機能は投稿の内容を含むプロンプトをクリップボードにコピーし、選択したチャットサービス（claude.ai または gemini.google.com）の新しいタブを開くだけです。本拡張機能自身はデータを外部へ送信しません。チャットへの貼り付けと送信は利用者自身が行い、送信内容の取り扱いは各サービスの規約・プライバシーポリシーに従います。

「APIで自動解析」方式：抽出処理のため、上記のページの内容・スクリーンショット・手動入力テキストを、利用者が設定画面で選択したAIサービスへ、利用者自身のAPIキーを用いて送信します。送信先は選択したサービスのいずれか一方のみです。

  • Claude を選択した場合：Anthropic, PBC のAPI（api.anthropic.com）。データの取り扱いは Anthropicのプライバシーポリシー および同社の利用規約に従います。
  • Gemini を選択した場合：Google LLC の Gemini API（generativelanguage.googleapis.com）。データの取り扱いは Gemini API 追加利用規約 および Googleのプライバシーポリシー に従います。無料枠で利用する場合、送信内容がGoogleのサービス改善に利用されることがあります。

上記以外の第三者に情報を提供・販売することはありません。開発者が運営するサーバーは存在せず、開発者が利用者の情報を受け取ることもありません。

4. 情報の削除

保存したレシピは本拡張機能の「保存済み」タブから個別に削除できます。本拡張機能をChromeから削除すると、APIキーと保存したレシピを含むすべてのデータが削除されます。

5. Chromeウェブストアのユーザーデータポリシーへの準拠

本拡張機能によるユーザーデータの使用は、制限付き使用（Limited Use）の要件を含む Chrome Web Store User Data Policy に準拠します。

6. 改定

本ポリシーを改定した場合は、本ページで公表します。
